Task Management System

A full-stack Task Management System built using Java, Spring Boot, React, and PostgreSQL.

Technologies Used
Java 21
Spring Boot 3
Spring Data JPA & Hibernate
PostgreSQL
React + Vite
JavaScript, HTML, CSS
Fetch API
Postman
Features
Create, view, and update tasks
Soft delete and permanent delete
Search tasks by title
Filter tasks by status and priority
Manage task descriptions and due dates
Task status: Pending, In Progress, Completed
Task priority: Low, Medium, High
Store task data in PostgreSQL
Project Structure
text
task-management-system/
├── task-manager-backend/
└── task-manager-frontend/

How to Run

Backend

bash
cd task-manager-backend
./mvnw spring-boot:run


Frontend

bash
cd task-manager-frontend
npm install
npm run dev


Configure your PostgreSQL database before starting the backend.
